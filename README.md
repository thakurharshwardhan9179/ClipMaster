# ClipMaster · Auto Shorts & Social Studio

AI-powered video clipping and multi-format social media studio (Facebook Reels, Instagram Reels, Quote Posts, Stories) with Copyright Shield and smart subtitle burning.

## Cloud Deployment (Hugging Face Spaces)
Runs automatically as a Docker container with:
- Node.js 20 runtime
- FFmpeg & ffprobe
- Python 3 with yt-dlp
- Multilingual & Indian Unicode fonts (Noto, Indic, FreeFont)

## Local Development
Run locally via VS Code or PowerShell:
```powershell
npm start
```
Open `http://localhost:4173`.
